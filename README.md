# Camera Uptime Management & SLA Monitoring Tool

Enterprise-grade application built for 13 Districts Dynamic 24/7 SLA Camera Uptime Monitoring, Collaborative Exception Proof Workflows, EMS Data Sync, and Daily Leaderboard.

## Project Structure
- `index.html` - Complete React web application code containing:
  - 🏆 Daily 13-District Leaderboard & Badges
  - 🧮 24/7 Dynamic Gross vs Net SLA Calculation Engine
  - 🛡️ Exception Handling & Proof Upload Approval Portal
  - 📊 District Drill-down Dashboards & Live Camera Matrix
  - ⚙️ EMS Sync Engine & 📑 Audit Exporter

## How to Run Locally

### Option 1: Open Directly
Double click `index.html` to launch it immediately in your web browser.

### Option 2: Run via Localhost Server
If you want to view it via `http://localhost:3000`:
```bash
python -m http.server 3000
```
Then open: [http://localhost:3000](http://localhost:3000)
